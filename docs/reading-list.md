# Reading List & Learning Resources

## Statistics for Quant Trading

- **Khan Academy — Statistics & Probability** (free)
  https://www.khanacademy.org/math/statistics-probability
  Covers: z-scores, normal distribution, correlation, regression, hypothesis testing.
  ~3 hours for the core concepts. You already use regression and R² — this fills in the theory.

- **"Quantitative Trading" by Ernest Chan** (book)
  Short, practical, code-oriented. Covers: backtesting pitfalls, mean reversion vs momentum, statistical edge detection, Kelly criterion for position sizing. Python examples but concepts translate directly.

## Momentum / Trend Following

- **"Stocks on the Move" by Andreas Clenow**
  Already read/implemented. Regression slope × R² ranking, ATR sizing, SMA 200 filter.

- **"Following the Trend" by Andreas Clenow**
  His earlier book on futures trend following. More relevant if expanding beyond equities.
